*********
Ros2
*********

Installation de ROS2 Jazzy à partir de la documentation Ros : `Installation sur Ubuntu avec deb packages <https://docs.ros.org/en/jazzy/Installation/Alternatives/Ubuntu-Install-Binary.html>`_. 

.. note::
   Si il y a une erreur lors de la commande de l'installation de ROS Jazzy, éxecuter la commande suivante : 
   .. code-block:: bash
      sudo apt update && sudo apt install curl -y
