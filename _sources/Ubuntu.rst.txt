*********
Ubuntu
*********

Linux Ubuntu est un système d’exploitation libre, gratuit, et simple d’utilisation.
Il est possible d'installer Ubuntu sur une Rasberry Pi à l'aide de l'outil Pi Imager téléchargeable à l'adresse suivante : https://www.raspberrypi.com/software/.

La version d'Ubuntu à installer est Ubuntu 24.04
2 types d'installation sont possibles
* Ubuntu Lite : version sans interface graphique, tout se fait via des commandes dans un terminal
* Ubuntu Desktop : version avec interface graphique, accès à l'explorateur de fichiers et à diverses applications préinstallées
